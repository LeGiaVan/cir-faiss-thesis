# CIR FAISS Thesis

## Cấu trúc thư mục
- `data/`: Chứa dữ liệu (không push lên git).
- `third_party/`: Chứa source code gốc của 3 bài báo bằng Git Submodule.
- `checkpoints/`: Chứa pre-trained weights.
- `src/`: Mã nguồn chính.
- `notebooks/`: Chứa các Jupyter Notebooks để test nhanh.

## Hướng dẫn cài đặt
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
